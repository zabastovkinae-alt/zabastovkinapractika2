# Практическая работа №2 — отчёт

## Результат 6. Сравнение детекции и семантической сегментации

В работе использован один и тот же видеоролик (~11 секунд) с кошкой на диване.
Кадры извлечены через ffmpeg с частотой 3 fps — получилось 34 кадра.

**Детекция (YOLOv8-seg в режиме детекции).** Модель обнаруживает отдельные
объекты, для каждого строит bounding box, определяет класс и confidence.
На первом кадре уверенно найдены: cat (0.88), couch (0.55), chair (0.49).
Все три класса входят в набор COCO (80 классов). Детектор хорошо отвечает
на вопрос «где объект», но не различает пиксели фона.

**Семантическая сегментация.** Та же модель YOLOv8-seg строит цветные маски
по классам — каждый пиксель относится к какому-либо классу. Границы объектов
видны точнее, чем рамки, но два объекта одного класса (например, две кошки)
могут слиться в одну маску. Легенда показывает соответствие цветов и классов.

**Ограничения.** Детекция быстрее, но не даёт формы объекта. Сегментация
требует больше памяти и времени инференса. Обе модели работают в рамках
предобученных классов COCO — экзотических объектов (телефон в руке, узор
на ткани и т.п.) не распознают. На Apple Silicon инференс ускоряется через
MPS (Metal Performance Shaders).
